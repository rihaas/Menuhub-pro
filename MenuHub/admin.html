MenuHub Admin

Manage menu stock, availability, prices and descriptions

One-time setup

  1. Create a Firebase project and enable Email/Password sign-in.
  2. Paste the Firebase web config into FIREBASE_CONFIG here and in index.html.
  3. Create the owner's account in Firebase Authentication.
  4. Replace admin@example.com in firestore.rules with the owner's email and publish the rules.
  5. Sign in and click Initialize menu once.

Do not hard-code a password in HTML. The browser config is not a password; Firebase Authentication and Firestore rules enforce access.

Owner sign in

Menu controls

Uncheck Available to mark an item sold out. Edit name, description or price, then save. Changes sync to customer menus when connected.
